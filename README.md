[README.md](https://github.com/user-attachments/files/32915095/README.md)# HTR — Schöffenratsprotokolle Frankfurt 1736-1737

Lecture automatique (HTR) des procès-verbaux du Schöffenrat de Francfort, ISG Frankfurt am Main, Best. H.02.25, Nr. 42 (1736) et Nr. 43 (1737), d'après les images publiques de digitalisate.frankfurt.de.
Segmentation : kraken 5.3 (modèle blla par défaut ; repli : profil de projection). Lecture : TrOCR `dh-unibe/trocr-kurrent-XVI-XVII` (A) et `dh-unibe/trocr-kurrent` (B), licence MIT, téléchargés depuis Hugging Face à l'exécution.
Sorties : `results/lines/*.jsonl` (toutes les lignes), `results/hits.csv` (lignes avec mot-clé), `results/crops/` (images de ces lignes), `results/summary.md`.
Les images restent celles de l'Institut für Stadtgeschichte ; ce dépôt ne les redistribue pas, hormis les découpes des lignes signalées.
Lecture automatique non vérifiée : toute transcription doit être contrôlée sur l'image.
